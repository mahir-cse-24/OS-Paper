# Retained predictive VM-placement extension

This directory is kept from the earlier Track 4 study. It is supplementary to the main Ubuntu/VMware workload experiment and is not used to fill missing VMware measurements.

The extension studies First-Fit, Best-Fit, regression-based proactive placement, a deliberate load shift, host utilization balance, overload/SLA events, migration count, predictor ablation, threshold sensitivity, and explanation confidence.
