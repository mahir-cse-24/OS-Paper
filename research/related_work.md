# Related work

The extension is framed around VM placement as a resource-allocation problem and uses published work on VM consolidation, migration cost, and prediction-aware placement.

- Beloglazov and Buyya, 2012, Energy Efficient Management of Virtual Machines in Data Centers for Cloud Computing. DOI: 10.1002/cpe.1867.
- Hsieh et al., 2020, prediction-aware dynamic VM consolidation. DOI: 10.1016/j.jpdc.2019.12.014.
- Jangiti and Shankar Sriram, 2018, VM placement and migration context. DOI: 10.1016/j.compeleceng.2018.03.029.
- Awad et al., 2022, resource-aware VM consolidation context. DOI: 10.1016/j.jpdc.2022.08.001.
